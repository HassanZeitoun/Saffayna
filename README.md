# Saffayna (صفّينا)

> Saffayna... bas mesh 3al hadideh

A personal budget tracker: log your spending, organize it with your own
categories and tags, attach receipt photos, and see where your money went.

## Tech stack
- Backend: ASP.NET Core (.NET 10), Clean Architecture, EF Core, PostgreSQL
- Frontend: Angular, PrimeNG, Tailwind CSS

## Status
Work in progress. Started November 2026.
