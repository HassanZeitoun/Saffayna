# Saffayna: working rules

- This is a learning project. The owner must understand every line of code.
- Keep code small and simple. Do not add abstractions unless asked.
- Before using a new concept, explain it in plain English. Then explain the code line by line. Use arabic when hard to demonstrate in english.
- Backend: ASP.NET Core (.NET 10), Clean Architecture (Domain, Application, Infrastructure, Api), EF Core, PostgreSQL, AutoMapper.
- Frontend: Angular (latest), PrimeNG + Tailwind CSS.
- Always use the latest stable versions.
- Work one small step at a time, then stop so the owner can commit.
- Never commit secrets (passwords, keys, connection strings with passwords).
